# 《缺口與驗收計劃（深入版）》— predict-hk-racing

**日期：**2026-10-28　**狀態：**已確認方向；執行中　**範圍：**沙田／跑馬地本地賽事<br>
**本頁只批准驗證，不批准宣稱已有預測優勢或盈利能力。**

## 1. 核心目標與邊界

目標不是增加模型、來源或特徵數量，而是證明三件事：**賽前資料可按時點重建、情報判斷可由獨立第三方重現、任何可選概率模型都在時間外表現優於預先聲明的基線。**消息／證據先行，原始賠率只作可選市場觀察；情報輸出不含勝出率，消息是否有增量價值由消融測試決定。

先分開四層，不得互相冒充：

1. **事實：**官方公布、原始頁面、影像及可直接觀察的部署。
2. **推論：**對能力、形勢及馬房部署支持度的不確定判斷。
3. **預測：**在指定截止時間、資料版本及模型版本下凍結的概率。
4. **結果：**官方名次、派彩及事前注項的結算；不得用結果反推真實意圖。

**暫不擴張：**海外賽事、新彩池、複雜集成模型、自動下注及未經驗證的固定消息權重。先完成一場最小閉環，再決定是否擴大樣本。

## 2. 專家層補充：不只是多收資料

| 深化方向 | 必做工作 | 可推翻／拒測條件 |
|---|---|---|
| 估計目標 | 核心係部署支持度、事實及形勢；可選模型先分開勝出率、位置率；以「場」為獨立分析單位，不把同場馬匹當完全獨立樣本 | 目標或評估單位不清，不開始建模 |
| 相反解釋 | 對騎師、配備及表現變化同時檢查體重、合約、檔期、步速、受阻、場地偏差及健康 | 只有單一故事、沒有反證或未知欄，不得列高置信 |
| 預先登記 | 封存基本面短名單、有效樣本規則、基線、測試窗口、門檻及排除規則後才接觸市場／賽果 | `market_blind` 倒填、賽後改門檻或揀窗口，相關結果無效 |
| 情報增量 | 在同一時間外窗口比較能力與能力＋情報特徵，做消融、校準及不確定區間 | 情報無增量價值時保留陰性結果，撤回或降權 |
| 預測與投注分離 | 情報不含勝率；概率指標與事前注項結算分開；價值評估使用官方派彩、全部成本及可成交時點 | 賽後揀注、漏報輸注或只用 ROI，不構成模型有效證據 |

## 3. 原始資料與有效樣本

不得從整理後摘要反推當時特徵。實際下載、保存、截圖轉錄及匯入步驟見[《原始資料獲取教學》](../predict-hk-racing/references/data-acquisition-guide.md)；消息分級與 claim 對應見[《消息來源與分析步驟》](../predict-hk-racing/references/intel-sources.md)。

最小原始層包括：

- HKJC 原始排位、逐馬往績、出賽聲明、配備及賽日變更；
- 官方賽果、派彩、競賽事件、研訊及獸醫紀錄；
- 可合法取得的賽事重播、分段、試閘、操練、場地、天氣及跑道資料；
- 騎練完整訪問或馬房正式公布，而非轉述金句；
- T-60／T-10 同場全馬、同一時點的 WIN／PLA 原始頁面或經獨立核對的截圖轉錄。

有效樣本是**相對模型需要**而定：沒有市場資料的場次不得進入市場對照或值博回測；只有賽果或最終賠率的場次不得當成完整賽前樣本。**200+ 只是數量目標，不是豁免條件；先報合格、排除及每項特徵覆蓋，再判斷樣本是否足夠。**

## 4. 缺口、工作與通過條件

| 優先級／缺口 | 本階段工作 | 驗收通過條件 |
|---|---|---|
| **P0｜as-of 時點資料鏈** | 保存原件、內容時間、首次可用時間、實際抓取時間、截止時間、SHA-256 及更正版本；所有特徵只做截止前 as-of join | 全場、全出賽馬及退出馬無遺漏；核心欄位 **100% 核對**；每項特徵可回溯原件；未來資料注入全部拒絕；最終賠率不得進入 T-60 卡；歷史重建不得混入 forward KPI |
| **P0｜情報 claim 與盲審** | 逐匹對比上仗／今仗配備、騎師及條件；每項分開觀察、推論、反證、未知及可推翻條件；兩名不知賽果且未見賠率的標籤者獨立抽查 | 引文與來源抽核 **100%**；公佈 Cohen’s κ 或 Krippendorff’s α、分歧及裁決；未解決分歧不得列高置信；騎師不同不得直接稱為選鞍；無證據必須顯示「證據不足」 |
| **P0｜賽前封存與獨立重現** | 封存全馬情報、支持／反證／未知、資料／程式哈希、依賴鎖及可信第三方時間證據；可選模型另存模型哈希；提供一鍵重建 | 未參與製作的第三方在乾淨環境重現相同輸入哈希、情報輸出及（如有）概率指標；序列化差異須事先聲明容差；Python 3.11／3.12 與防洩漏測試全綠；無法證明賽前形成的記錄排除出 forward KPI |
| **P1｜有效歷史樣本與時間外價值** | 按日期 expanding-window walk-forward，對照預先登記的均勻無資訊內部基準及現任 champion；做情報消融、log loss、Brier、校準及按賽事／賽日分組的 block bootstrap | 有效樣本及覆蓋達預先登記要求；原始與多重比較調整後區間均通過；required ablation 完整；50 場只可作初評，不等於穩定優勢；未通過版本必須 `rejected` |
| **P1｜修正與投注結論** | 復盤只分資料錯、提取錯、特徵／形勢錯、校準錯及隨機波動；新想法進入 hypothesis ledger，以新版本驗證 | 不因單場改權重，不覆蓋舊分析或理由；未通過版本沿用舊版，冇舊版就只出情報；價值報告含官方派彩、全部事前注項、成本、turnover、最大回撤及不確定性 |

## 5. 外部證據：誰可以證明甚麼

| 要證明的層次 | 獨立證據 | 不能接受的替代 |
|---|---|---|
| 事實正確 | 官方原件＋第二輪獨立提取／核對 | 由同一模型重讀自己的輸出 |
| 引文與標籤可靠 | 獨立盲審、一致率及分歧裁決 | 原作者替自己的 claim 背書 |
| 賽前已存在 | 不可變登記、manifest 哈希及可信第三方時間證據 | 本機修改時間或事後補寫時間 |
| 輸出可重現 | 第三方在乾淨環境重跑並核對哈希、概率及指標 | 在原工作區再次執行成功 |
| 時間外有價值 | 預先封存、從未參與開發的未來賽事及官方結果 | 同一批歷史資料重複回測後揀最佳版本 |
| 投注結果真實 | 事前完整注項登記及官方派彩，包括全部輸注 | 賽後展示命中注項或截圖 |

沒有外部方法可以百分百證明練馬師的內心意圖，也不能保證下一場命中；外部證據只能提高資料、形成時間、推論過程及時間外表現的可信度。

## 6. 驗收順序與交付

1. **最小閉環：**先完成一場「原件 → 基本面封存 → 情報 claim／反證／未知 → `analyze` 凍結 → 可選原始市場觀察 → 官方結果核查 → 獨立重跑」。跑通只證明工程正確。
2. **歷史有效樣本：**逐場列合格／排除原因及特徵覆蓋，不為湊數放寬時點規則；陰性結果同樣交付。
3. **前瞻驗收：**持續累積真正賽前記錄，達預先登記樣本量後才評價可選模型；歷史重建只作工程測試及輔助回測。
4. **交付物：**原件與 manifest、逐匹 claim 登記冊、覆蓋／排除報告、不可變情報分析、可選模型嘅時間外指標與消融、獨立重現記錄、假設及版本修正台帳。

## 7. 不可驗證事項與拒測線

賽果不能證明練馬師真實意圖，一場命中不能證明長期有效，歷史回測不能冒充當日實戰，任何結果都不保證盈利。核心場次資料衝突、來源無法核實、時間戳缺失或關鍵欄位不足時，必須降級為定性分析或拒測，不得補猜。賽馬高方差，只以可承受損失作娛樂預算，不追輸。
